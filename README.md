# _Buk Baibel long Tok Pisin_ Aquifer Resource

This repository (`TokPisinBible2008`) contains an Aquifer Bible resource with resource-level metadata and content files in USFM and USX formats.

## Structure

The repository is organized by language codes, with each language folder containing USFM and USX content files.
